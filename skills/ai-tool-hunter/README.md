# 🛠️ AI 工具猎人

一个用于发现最近正在冒头、突然爆火、刚发布或重大更新的 AI 工具，并判断它是否值得做成公众号选题的 Skill。

## 能做什么

- 搜索今天 / 最近 7 天的新 AI 工具
- 追踪 GitHub 最近爆火的 AI 开源项目
- 发现海外正在火、中文互联网尚未大量报道的 AI 产品
- 区分“刚发布”和“老工具因重大更新重新爆火”
- 核验 GitHub、Product Hunt、Reddit、X、Hacker News、YouTube、媒体等热度信号
- 按 100 分模型评估公众号选题价值
- 输出热点型、工具型、认知型 3 个写作角度
- 明确给出：建议马上写 / 可以写 / 继续观察 / 不建议写

## 评分维度

| 维度 | 分值 |
|---|---:|
| 新鲜度 | 20 |
| 热度 | 20 |
| 产品创新 | 20 |
| 普通人实用性 | 15 |
| 公众号传播潜力 | 15 |
| 中文互联网信息差 | 10 |
| 总分 | 100 |

评级：

- 🔥 S级 85～100：强烈建议马上写
- 🟢 A级 75～84：值得写
- 🟡 B级 60～74：继续观察
- ⚪ C级 <60：不建议写

## 核心原则

**新鲜度 > 名气**

**增长速度 > 总热度**

**信息差 > 人人都知道**

**真实价值 > 营销话术**

**宁缺毋滥 > 凑榜单**
